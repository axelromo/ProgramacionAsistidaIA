## 📖 Sobre el Proyecto

Este repositorio contiene ejercicios de JavaScript desarrollados durante el curso de **Programación Asistida por IA**. Los ejercicios cubren diferentes conceptos y técnicas de programación en JavaScript, desde fundamentos hasta temas más avanzados.

### 🎯 Objetivos

- Practicar conceptos fundamentales de JavaScript
- Desarrollar habilidades de programación asistida por IA
- Aplicar buenas prácticas en el desarrollo de código JavaScript
- Documentar y compartir el aprendizaje adquirido

### 💻 Tecnologías Utilizadas

Este repositorio se enfoca exclusivamente en **JavaScript**:

- JavaScript (ES6+)
- Node.js (para ejercicios de backend)
- NPM (gestión de paquetes)

## ⚙️ Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:

- **Git**: Para el control de versiones
- **Node.js**: Para ejecutar JavaScript en el entorno
- **NPM**: Gestor de paquetes de Node.js
- **Editor de código**: VS Code (recomendado), u otro de tu preferencia

### Verificación de Requisitos

```bash
# Verificar instalación de Git
git --version

# Verificar instalación de Node.js
node --version

# Verificar instalación de NPM
npm --version
```

## 🚀 Instalación

### Clonar el Repositorio

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/programacion-asistida-ia.git

# Navegar al directorio del proyecto
cd programacion-asistida-ia
```

### Configuración del Entorno

```bash
# Instalar dependencias globales (si aplica)
npm install -g some-package

# Instalar dependencias locales (si el ejercicio lo requiere)
npm install
```

## 📝 Uso

### Ejecutar Ejercicios

Para ejecutar los ejercicios de JavaScript, tienes varias opciones:

#### Usar Node.js (Recomendado)

```bash
# Navegar al directorio del ejercicio
cd ejercicios/01-fundamentos

# Ejecutar el archivo JavaScript
node ejercicio.js
```

#### Usar NPM Scripts (si aplica)

```bash
# Navegar al directorio del ejercicio
cd ejercicios/01-fundamentos

# Ejecutar usando scripts de npm
npm run test
# o
npm start
```

### Instrucciones Específicas

Cada ejercicio puede tener instrucciones específicas detalladas en su propio archivo README.md dentro del directorio correspondiente.
